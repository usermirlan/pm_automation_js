# Автоматизация процессов управления проектами с использованием языка программирования JavaScript

Данный проект представляет собой современную Full-stack платформу (Kanban-доска) для управления проектами, ключевой особенностью которой является **полная автоматизация жизненного цикла задач**. Система не просто отображает задачи, но и активно взаимодействует с ними с помощью встроенных алгоритмов и событийно-ориентированной архитектуры.

## 🚀 Основные возможности автоматизации

В системе реализованы три ключевых сценария автоматизации, которые минимизируют ручное управление:

1.  **Автоматический переход (Workflow Automation):** Робот на стороне бэкенда отслеживает новые задачи. Если задача находится в статусе "К выполнению" более 10 секунд, система автоматически переводит её в статус "В процессе", запуская таймер выполнения.
2.  **Интеллектуальная обработка контента (Smart Content Solver):** Система анализирует названия задач. Если название содержит математическое выражение (например, `2 + 2`), робот самостоятельно вычисляет результат, обновляет название задачи и переводит её в статус "Готово".
3.  **Авто-инициализация проектов (Project Auto-Initializer):** При создании задачи с префиксом `Проект:`, система распознает это как запуск нового проекта и автоматически генерирует структуру подзадач (Планирование, Разработка, Тестирование) с привязкой к основному проекту.
4.  **Автоматический учет времени (Auto Time Tracking):** Система фиксирует точное время начала и завершения работы над каждой задачей, предоставляя аналитику о затраченном времени сразу после перемещения задачи в финальную колонку.

## 🛠 Технологический стек

Проект реализован на базе **JavaScript/TypeScript** экосистемы:

*   **Frontend:** React, Tailwind CSS, dnd-kit (для реализации Drag-and-drop), Socket.io-client.
*   **Backend:** NestJS (Node.js framework), EventEmitter2 (для внутренней шины событий), Socket.io.
*   **Database:** SQLite + Prisma ORM.
*   **Architecture:** Monorepo (Turborepo), обеспечивающая тесную интеграцию фронтенда и бэкенда.
*   **Real-time:** WebSockets для мгновенной синхронизации данных между всеми клиентами без перезагрузки страницы.

## 📐 Архитектура системы

Система построена на **событийно-ориентированной архитектуре (EDA)**:
1.  Пользователь совершает действие на фронтенде.
2.  Сервер принимает запрос, сохраняет данные в БД и генерирует событие.
3.  Слушатели событий (Listeners) перехватывают это событие и запускают соответствующие автоматизированные скрипты.
4.  Результат автоматизации мгновенно рассылается всем подключенным пользователям через WebSockets.

## 📦 Как запустить проект

1.  Установите зависимости в корне проекта:
    ```bash
    npm install
    ```
2.  Запустите проект в режиме разработки:
    ```bash
    npm run dev
    ```
    *   Фронтенд будет доступен по адресу: `http://localhost:5173`
    *   Бэкенд будет доступен по адресу: `http://localhost:3000`
