# ПОЯСНИТЕЛЬНАЯ ЗАПИСКА К ПРОЕКТУ

**Тема:** Автоматизация процессов управления проектами с использованием языка программирования JavaScript

## 1. Введение
В современных условиях эффективное управление проектами требует не просто хранения данных, но и их интеллектуальной обработки. Актуальность данной работы заключается в переходе от статических систем управления задачами (Kanban-досок) к активным системам, способным самостоятельно выполнять рутинные операции, контролировать сроки и анализировать контент.

**Цель проекта:** Разработка программного комплекса для автоматизации ключевых бизнес-процессов управления проектами на базе стека технологий JavaScript.

## 2. Технологический стек и обоснование выбора
Для реализации проекта был выбран современный стек технологий:
*   **Node.js (NestJS):** Позволяет создавать высокопроизводительные серверные приложения с модульной архитектурой.
*   **React.js:** Обеспечивает создание динамичного и отзывчивого пользовательского интерфейса.
*   **TypeScript:** Позволяет минимизировать ошибки на этапе разработки за счет строгой типизации.
*   **Socket.io:** Выбран для обеспечения синхронизации данных в режиме реального времени, что критично для командной работы над проектами.
*   **Prisma ORM & SQLite:** Обеспечивают надежное хранение данных и высокую скорость разработки.

## 3. Описание архитектуры автоматизации
Центральным звеном проекта является **событийно-ориентированная модель**. Система не выполняет действия линейно, а реагирует на изменения состояния данных.

### Ключевые модули автоматизации:
1.  **Модуль управления жизненным циклом (Auto-Workflow):** Реализован на базе отложенных задач. При создании задачи сервер инициализирует таймер, который по истечении времени проверяет состояние задачи и, при необходимости, принудительно переводит её на следующий этап.
2.  **Модуль интеллектуальной обработки (Content Intelligence):** Использует регулярные выражения (RegEx) для анализа названий задач. При обнаружении математических структур или ключевых слов (триггеров), система перехватывает управление и выполняет логическую операцию без участия пользователя.
3.  **Модуль иерархической автоматизации (Project Initializer):** Позволяет автоматизировать создание структуры проекта. Использование триггера `Проект:` запускает рекурсивный процесс создания связанных подзадач, что сокращает время на инициализацию новых рабочих областей.

## 4. Практическая значимость
Разработанная система демонстрирует, как использование JavaScript позволяет автоматизировать:
*   **Контроль времени:** Исключение "простаивающих" задач в очереди.
*   **Снижение нагрузки на менеджера:** Автоматическое формирование структуры работ.
*   **Точность отчетности:** Сбор метрик о времени выполнения задач без ручного ввода.
